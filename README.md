# Work Receipts gate: live demo

![Canonical Work Receipts mascot](https://iamgodofall.github.io/work-receipts/mascot/full-body.png)

This repository demonstrates the [Work Receipts](https://github.com/iamGodofall/work-receipts) pull-request gate on real GitHub pull requests.

The gate passes a pull request only when it carries a receipt that is signed by a trusted key (`7df6:ffd2:5c80:d5a7:4694:8164:363b:8bee`), is internally consistent, has a **verified** verdict, and covers exactly the pull request's code by git tree hash.

The workflow pins the Work Receipts v0.2.1 action to its full release commit SHA rather than a moving branch or tag. Update the pin deliberately when adopting a newer release, then verify both the passing and failing pull-request scenarios again.

| Pull request | What happened | Expected gate result |
| --- | --- | --- |
| Verified agent change | Change made in scope, acceptance check passed, receipt committed with the code | Pass |
| Code edited after the receipt | Same change, then one line edited after the receipt was generated | Fail: the receipt covers a different tree |

How the receipts were produced: the session events were generated by driving the shipped plugin hooks (`plugin/bin/hook.js`) with a script that simulates a Claude Code session, then `cli.js receipt` ran the real acceptance check (`npm test`) and signed the receipt. This is not a recording of a live Claude Code session.

Verify both outcomes locally:

```bash
git clone https://github.com/iamGodofall/work-receipts-demo
git clone https://github.com/iamGodofall/work-receipts
cd work-receipts-demo

# The signed receipt matches the exact code in this pull request.
git fetch origin pull/1/head:demo-verified
git switch demo-verified
node ../work-receipts/plugin/bin/cli.js verify .receipts/sessions/demo-verified/receipt.json --expect-key 7df6:ffd2:5c80:d5a7:4694:8164:363b:8bee --tree HEAD

# The code changed after receipt generation, so verification must fail.
git fetch origin pull/2/head:demo-edited
git switch demo-edited
node ../work-receipts/plugin/bin/cli.js verify .receipts/sessions/demo-edited/receipt.json --expect-key 7df6:ffd2:5c80:d5a7:4694:8164:363b:8bee --tree HEAD
```

The first command is expected to succeed. The second is expected to exit non-zero because the current Git tree differs from the tree covered by the signed receipt.
